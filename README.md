**Short description:** Interactive D3.js dashboards exploring relationships between news headlines, Metropolitan Police crime counts and public perception (MOPAC). Click a badge or image to open the live demo.

**How to use**
1. Click a **Live demo** badge or the preview image to open the dashboard.  
2. Use the borough selector and time slider to explore perception vs recorded crime.  
3. For headline analysis, select a crime type to view headline‑level media signals and perception residuals.

**Repository contents**
- `/notebooks` — data cleaning and regression notebooks.  
- `/scripts` — pipeline scripts (GDELT ingestion, NLP preprocessing).  
- `/pages` — deployed dashboard pages (GitHub Pages).
- `/Source Code` — Python code used for Data Mining and Regression Analysis for the Dashboards
